# Evaluación comparativa de micrófonos · Jocotoco · v0.2.0

https://jocoacoustics.github.io/evaluacion_microfonos_2026_nov/

Este proyecto permite ejecutar **un solo notebook de Google Colab** para evaluar dos grabaciones simultáneas frente a la fuente digital reproducida por parlante y generar un informe **Papiro interactivo** en `githubpages/index.html`. Sin Atlas, Streamlit ni servidor de aplicaciones. El navegador utiliza un archivo local de Plotly.
